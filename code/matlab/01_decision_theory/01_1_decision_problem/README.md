# 1.1 — O problema de decisão (MATLAB/Octave)

- Funções: `MatrizDecisao.m`, `Dominadas.m`
- Exemplo: `ex01_1_decision_problem.m` (moeda (10 €), tendas (matriz de lucros), dado (15 €) e dominância no investimento (os títulos são dominados pelas obrigações)).
- Tradução da versão Python (`code/python/01_decision_theory/01_1_decision_problem/`), com a mesma saída.

## Como correr

No MATLAB ou no GNU Octave, abrir `ex01_1_decision_problem.m` e carregar em Run (ou `run('ex01_1_decision_problem.m')`).
O capítulo inteiro corre com `../ex01_capitulo.m`, que é o ficheiro aberto pelo link do MATLAB Online.

A última linha é `confere com os slides: sim`. Os slides usam vírgula decimal; o código usa o ponto.
