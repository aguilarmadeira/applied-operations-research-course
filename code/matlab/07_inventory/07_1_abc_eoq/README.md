# 7.1 — Classificação ABC e quantidade económica de encomenda (MATLAB/Octave)

- Funções: `Abc.m`, `Qee.m`, `CustoQee.m`
- Exemplo: `ex07_1_abc_eoq.m` (ABC da fábrica de tintas (A: P1, P2, P3), QEE do dióxido de titânio (2121 kg, 49 697,06 €, ponto de encomenda 461,5 kg), robustez, e os Exemplos 1 (ABC) e 2 (transístores, 988 unidades) da aula).
- Tradução da versão Python (`code/python/07_inventory/07_1_abc_eoq/`), com a mesma saída.

## Como correr

No MATLAB ou no GNU Octave, abrir `ex07_1_abc_eoq.m` e carregar em Run (ou `run('ex07_1_abc_eoq.m')`).
O capítulo inteiro corre com `../ex07_capitulo.m`, que é o ficheiro aberto pelo link do MATLAB Online.

A última linha é `confere com os slides: sim`. Os slides usam vírgula decimal; o código usa o ponto.
