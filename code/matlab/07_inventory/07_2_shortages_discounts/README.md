# 7.2 — Rutura planeada e descontos de quantidade (MATLAB/Octave)

- Funções: `Rutura.m`, `Descontos.m` (usa `Qee` de 7.1 para a comparação sem rutura)
- Exemplo: `ex07_2_shortages_discounts.m` (tinta premium com rutura (160 latas, ponto de encomenda -16,9, 1200 contra 1385,64 €), descontos no dióxido de titânio (6000 kg, 48 180 €), e os Exemplos 3 (loja AAA, 400 unidades) e 4 (componentes, 6000) da aula).
- Tradução da versão Python (`code/python/07_inventory/07_2_shortages_discounts/`), com a mesma saída.

## Como correr

No MATLAB ou no GNU Octave, abrir `ex07_2_shortages_discounts.m` e carregar em Run (ou `run('ex07_2_shortages_discounts.m')`).
O capítulo inteiro corre com `../ex07_capitulo.m`, que é o ficheiro aberto pelo link do MATLAB Online.

A última linha é `confere com os slides: sim`. Os slides usam vírgula decimal; o código usa o ponto.
